# 🌿 Sedra Green Action Hub — My Progress Dashboard

لوحة تفاعلية شاملة لمتابعة مسار تطوير وإطلاق منصة **Sedra Green Action Hub** خطوة بخطوة ضمن دورة الـ Vibe Coding والجاهزية المهنية.

---

## 🌟 الميزات الرئيسية (Key Features)

- **8 مراحل متكاملة (8 Project Stages):** تغطي مسار الرحلة من الاستراتيجية وتحديد المشكلة إلى التصميم والتطوير والنشر على Vercel والعرض المهني (Pitch Deck).
- **55 مهمة موثقة (55 Structured Tasks):** مع معايير اكتمال واضحة (Definition of Done) لكل مهمة بالعربية والإنجليزية.
- **تتبع الأولويات وتواريخ الاستحقاق (Priority & Due Dates):** تصنيف الأولويات (عالية، متوسطة، منخفضة) مع تنبيه تلقائي للمهام المتأخرة (Overdue).
- **الساعات المخططة والفعلية (Time Tracking):** احتساب الوقت المنقضي لمتابعة الجهد الفعلي.
- **روابط الأدلة والملاحظات (Evidence Links & Notes):** إمكانية إرفاق روابط المستودعات، التصاميم، والملاحظات الشخصية لكل مهمة.
- **بحث وتصفية ذكية (Search & Filtering):** تصفية المهام حسب الحالة والأولوية مع بحث فوري.
- **مساحة التركيز اليومي (Daily Focus):** تدوين الهدف الرئيسي لليوم والخطوة القادمة لتعزيز الإنتاجية.
- **سجل القرارات والعقبات (Decisions & Blockers Log):** توثيق الأسئلة، القرارات، والتحديات وحلولها.
- **حفظ تلقائي محلي (Instant Auto-Save):** حفظ فوري لجميع التعديلات عبر `localStorage`.
- **نسخ احتياطي واستعادة (Backup & Restore):** تصدير واستيراد البيانات بصيغة JSON.
- **ثنائي اللغة بالكامل (Bilingual RTL/LTR):** دعم سلس للعربية والإنجليزية.
